# Limit Aktör 3 TYT Çözümleri

Bu depo, GitHub Pages üzerinde doğrudan yayınlanabilecek statik bir TYT denemesi çözüm sitesidir.

## İçerik

- `index.html`: Sayfa iskeleti
- `styles.css`: Arayüz stilleri
- `app.js`: Test cevapları, soru çözüm kartları ve görsel bağlantıları
- `assets/pages/`: Kullanıcının gönderdiği deneme sayfası görselleri

## Yerelde görüntüleme

```bash
python3 -m http.server 8000
```

Ardından tarayıcıda `http://localhost:8000` açılabilir.
